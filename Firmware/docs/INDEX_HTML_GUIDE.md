# index.html(マクロ設定ツール)の使い方

`index.html` は、マクロパッドの 10 個のスイッチに割り当てるマクロを GUI で作り、
Web Serial (COMポート) 経由で本体とリアルタイム同期・書き込みをしたり、364 バイトの設定データ (.bin) として保存・読み込みするためのツールです。

- ブラウザで `index.html` を開くだけで動きます(サーバー・インストール不要、オフライン可)。
- 対応ブラウザ(Chrome / Edge など)で「COMポート選択」を行うと、本体からの設定読み込み・リアルタイム送信・EEPROM保存が画面上から直接操作できます。
- 画面の設定は**ブラウザ上にだけ**存在します。ページを閉じる・再読み込みすると消えるので、オフラインで作業する場合は `.bin` を保存してください(自動保存はありません)。
- 本体側の保存・Serial コマンドについては `EEPROM_SERIAL_GUIDE.md` も参照してください。

## 1. 画面の構成

画面上部の操作バー、通信状態を確認できるコンソール、その下に並ぶ 10 本のスイッチ列(横スクロール)で構成されます。

### 操作バー

| ボタン | 内容 |
|---|---|
| COMポート選択 / COMポート切断 | Web Serial API でマクロパッドに接続/切断する(接続時に本体設定を取得) |
| 本体へ保存 (save) | 現在の画面の設定を本体の EEPROM に永続保存する |
| デフォルト設定に戻す | 本体の EEPROM を消去(`erase yes`)し、初期状態に戻して再読み込みする |
| 364B バイナリ (.bin) 保存 | 現在の設定を `macro_config.bin`(364 バイト)としてファイル保存 |
| .bin を読み込む | 保存済みの `.bin`(364 バイト)を画面に読み込む |
| 全クリア | すべてのスイッチを「未設定」に戻す(確認ダイアログあり) |
| 更新日時 | 設定データのタイムスタンプ(日時)を表示 |
| ☀️ ライトモード / 🌙 ダークモード | 表示テーマの切り替え(選択はブラウザに記憶され、未選択なら OS の設定に従う) |

### 通信コンソール (CONSOLE MONITOR)

操作バーの下に配置されたシリアル通信ログモニターです。

- **接続状態バッジ**: 「未接続(赤)」または「接続中(緑)」を表示。
- **ログ表示領域**: 送信データ(`Tx >`)、受信データ(`Rx <`)、システムログ(`SYS:`)をリアルタイム表示。
- **ログ消去**: 蓄積された通信ログをクリア。

### スイッチ列

左から順に、次の 10 スイッチです(Serial の `sw` 番号と同じ順序)。

| sw | 列の名前 |
|---|---|
| 0 | 右上sw |
| 1 | 右下sw |
| 2 | 左上sw |
| 3 | 左下sw |
| 4 | 上ダイヤル押し込みsw |
| 5 | 下ダイヤル押し込みsw |
| 6 | 上ダイヤル回転(時計回り) |
| 7 | 上ダイヤル回転(反時計回り) |
| 8 | 下ダイヤル回転(時計回り) |
| 9 | 下ダイヤル回転(反時計回り) |

各スイッチには最大 **16 ステップ** (Step #1 〜 #16) を設定できます。
画面上では「設定済みの最終ステップ + 未設定 1 行」が表示され、設定を入力すると自動的に次の行が追加されます。

## 2. 1 ステップの設定方法

各ステップには次の部品があります。

| 部品 | 内容 |
|---|---|
| ☰ (ドラッグハンドル) | ドラッグしてステップの並べ替えや他スイッチへの移動(Ctrl+ドロップでコピー) |
| Step #N / 操作ボタン | ステップ番号の表示。すぐ下に複製する「⧉」ボタンと削除する「✕」ボタン |
| 判定表示(緑文字) | 現在の設定内容の確認用。`判定: 左 Ctrl`、`判定: Wait (100ms)`、`未設定` など |
| 16 進数入力欄(黄色/青色) | コードを直接入力する欄(例: `0x0004`)。下のメニューと連動 |
| 動作の種類(プルダウン) | キーをどう扱うか(下表) |
| キー選択ボタン | 押すとメニューが開き、キーを選べる |
| 時間入力欄(Wait のときだけ表示) | 待ち時間をミリ秒で指定 |

### 動作の種類

| 選択肢 | type | 意味 |
|---|---|---|
| 未設定 (Null) | 00 | 何もしない(空のステップ) |
| 00: 押す (Down) | 00 | キーを押す(離すまで押しっぱなし) |
| 01: 離す (Up) | 01 | キーを離す |
| 10: 打鍵 (Tap) | 10 | 押して離す |
| 11: 制御 (Cmd / Delay) | 11 | 「全キー一括解除」または「指定時間待つ」 |

- メディアキー(音量・再生など、メニューの「(Consumer)」系)は、種類に関わらず常に「押して離す」動作になります。
- `Down` で押したキーは `Up` か「全キー一括解除」で離してください(マクロ終了時に押しっぱなしのキーは自動解除されます)。

### キーの選び方(メニュー)

1. 動作の種類を選ぶ(先に種類を決めてください。制御に変えるとキー設定はリセットされます)。
2. キー選択ボタンを押すと、カテゴリ一覧のメニューが開きます。
3. カテゴリにマウスを乗せるとキー一覧が出るので、クリックして選びます。
4. メニューの外をクリックすると閉じます。

メニューのカテゴリ:

- ファンクションキー (F1〜F24)
- アルファベット (A〜Z)
- 数字 (メインキー)
- 修飾キー (Modifiers)
- 制御・編集・矢印キー
- メディア再生・音量 (Consumer)
- Web・ブラウザ操作 (Consumer)
- アプリ起動・システム (Consumer/System)
- 記号キー (JIS)
- テンキー (Keypad)

動作の種類が「制御」のときは、カテゴリの代わりに次の 2 つが表示されます。

| 項目 | 内容 |
|---|---|
| 全キー一括解除 (All Release) | 押しているキーをすべて離す |
| 指定時間待つ (Delay ms) | 指定した時間だけ待つ。時間入力欄が表示される |

### 待ち時間(Delay)

- 時間入力欄にミリ秒を 10 進数で入力します(**1〜65535**、初期値 100)。
- 入力に合わせて 16 進数入力欄も自動で更新されます。

### 16 進数入力欄で直接指定する

メニューにないキーは、16 進数入力欄にコードを直接入力できます。

- `0x` は付けても付けなくても構いません(例: `0x0004` と `4` は同じ)。
- 通常キーは 1 バイトの HID コード(`00`〜`FF`)、メディアキー(Consumer)は `80xx` 形式です。
- メニューにある名前と一致すればキー名が、ない場合は `カスタム (0x....)` と表示されます。
- 動作の種類が「制御」のとき、`0` 以外の値は**待ち時間(ms)**として扱われます(`0` は全キー一括解除)。

### ステップの編集・並べ替え

- **並べ替え・移動**: 行左端の `☰` をドラッグして、同じスイッチ内での順序入れ替えや、別のスイッチ列へ移動できます。
- **コピー(複製)**: `Ctrl` キーを押しながら `☰` をドラッグ＆ドロップするか、ステップ右上の `⧉` ボタンを押すとすぐ下に複製されます。
- **削除**: ステップ右上の `✕` ボタンを押すと該当ステップが削除され、後ろのステップが前詰めで繰り上がります。

## 3. 設定の出力・読み込み

### A. Web Serial (COMポート) による本体との連携・書き込み

1. 「**COMポート選択**」を押し、接続するデバイス(マクロパッド)のシリアルポートを選択します。
2. 接続成功時、自動的に本体から現在の設定データが読み込まれ(`dump`)、画面に反映されます。
3. 画面上で設定を変更すると、変更内容がリアルタイムで本体の RAM 上に送信(`load`)されます。
4. 設定が完了したら「**本体へ保存 (save)**」を押すと、本体の EEPROM に永続保存されます。
5. 初期状態に戻したい場合は「**デフォルト設定に戻す**」を押すことで EEPROM が消去(`erase yes`)され初期化されます。

`load`(リアルタイム送信)だけでは RAM 上の変更にとどまり、`save` するまで電源を切ると元に戻ります。

### B. `.bin` 保存 / 読み込み(バックアップ・編集の再開)

- 「**364B バイナリ (.bin) 保存**」で `macro_config.bin` が保存されます。
- 「**.bin を読み込む**」で、保存した `.bin` を画面に復元できます。**364 バイト以外のファイルはエラー**になります。
- 読み込むと現在の画面の内容はすべて上書きされます。接続中の場合はリアルタイムで本体にも自動送信されます。
- `.bin` に含まれるタイムスタンプは、保存・更新した時刻から自動作製されます。

## 4. 使用例

### 右上ボタンを Ctrl+Shift+Esc にする(sw 0)

| Step | 動作の種類 | キー |
|---|---|---|
| 1 | 00: 押す (Down) | 左 Ctrl |
| 2 | 00: 押す (Down) | 左 Shift |
| 3 | 10: 打鍵 (Tap) | Esc |
| 4 | 11: 制御 (Cmd / Delay) | 全キー一括解除 |

Step 5 以降は「未設定」のままにします。

### 押してから少し待って別のキーを打つ

| Step | 動作の種類 | キー / 値 |
|---|---|---|
| 1 | 10: 打鍵 (Tap) | 左 Win/GUI |
| 2 | 11: 制御 (Cmd / Delay) | 指定時間待つ → `500` ms |
| 3 | 10: 打鍵 (Tap) | C |

## 5. 設定データの形式(参考)

`.bin` と Serial 送信される `load` パケットは同じ 364 バイトの形式です。

| オフセット | サイズ | 内容 |
|---|---|---|
| 0 〜 3 | 4 B | タイムスタンプ(2026-01-01 00:00:00 UTC からの経過秒、リトルエンディアン) |
| 4 〜 363 | 36 B × 10 | スイッチ 0〜9 の設定 |

1 スイッチ(36 B)は 4 ステップ分のブロック(9 B)× 4 です。

| ブロック内の位置 | サイズ | 内容 |
|---|---|---|
| 0 | 1 B | 4 ステップ分の type(2 bit ずつ。ステップ 1 が下位 2 bit) |
| 1 〜 8 | 2 B × 4 | 各ステップの code(リトルエンディアン) |

※送信・保存時には、各スイッチ内で途中にある「未設定」ステップの隙間が自動的に前詰めで処理されます。

## 6. 注意事項・トラブルシュート

| 症状 | 確認すること |
|---|---|
| ページを閉じたら設定が消えた | 自動保存はありません。`.bin` を保存するか本体へ `save` してください |
| Web Serial 接続ができない | Google Chrome や Microsoft Edge などの対応ブラウザを使用しているか確認してください |
| 接続すると画面の設定が消えた | 接続時に本体内の設定(`dump`)を読み出して画面を上書きするため、接続前に未保存データがある場合は `.bin` 保存でバックアップしてください |
| `.bin` を読み込むとエラーになる | ファイルが 364 バイトか確認(別形式・壊れたファイルは不可) |
| 「全クリア」で全部消えた | 元に戻せません。事前に `.bin` を保存しておいてください |
| 待ち時間が反映されない | 動作の種類が「11: 制御 (Cmd / Delay)」で、「指定時間待つ」を選んでいるか確認 |
| 設定したのに本体が電源オフで元に戻る | 「本体へ保存 (save)」ボタンを押したか確認(押さないと EEPROM に書き込まれません) |
