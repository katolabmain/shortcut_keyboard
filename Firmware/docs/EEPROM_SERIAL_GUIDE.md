# マクロ設定の EEPROM 保存と Serial での変更方法

マクロ設定(364 バイト)は Pico W のフラッシュ末尾(EEPROM エミュレーション領域)に保存されます。
ファームを書き込み直した後でも、USB の Serial(CDC)から中身を確認・変更できます。

## 1. 起動時の動作

| EEPROM の状態 | 起動時の動作 |
|---|---|
| 有効なデータがある | その内容でマクロが動く。接続時に `Config source: EEPROM` と表示 |
| 未書き込み / 破損 / 他のファームの残骸 | `lib/MacroManager/macro_config.h` の既定値で動く。`Config source: built-in default` と表示 |

- 「有効」の判定は、マジック(`0x4D43`)と CRC16 が両方一致したときだけです。
  EEPROM 領域は UF2 を書き込んでも消えないため、以前のファームのデータが残っていても誤読しません。
- 既定値(`macro_config.h`)は常にバックアップとして内蔵されています。

### EEPROM 上のレイアウト

| オフセット | サイズ | 内容 |
|---|---|---|
| 0 〜 363 | 364 B | 設定データ(先頭 4 B = タイムスタンプ、続けて 36 B × 10 スイッチは、index.html の `.bin` と同一形式) |
| 364 〜 365 | 2 B | マジック `0x4D43`(リトルエンディアン) |
| 366 〜 367 | 2 B | 設定データの CRC16-CCITT(リトルエンディアン) |

## 2. Serial への接続

1. USB でデバイスを PC に接続します。
2. 115200 bps の Serial ターミナルで開きます(例: `pio device monitor`、Tera Term、PuTTY)。
3. 接続すると次のように表示されます。

```
Serial connected
RP2040 keyboard Composite Device
Current timestamp: 1767225600 (2026-01-01 00:00:00 UTC)
Config source: built-in default
Type 'help' for config commands.
```

- 改行は CR・LF・CRLF のどれでも構いません。
- 入力した文字は既定でエコーバックされます。二重に表示される場合は `echo off` を送ってください。
- `[` で始まる行(`[Macro] ...`、`[HID Send] ...`)はファームのログです。コマンドの返答は `OK` または `ERR` で始まります。

## 3. コマンド一覧

`sw` は 0〜9、`step` は 1〜16 です。16 進数は `0x` を付けても付けなくても構いません。

| コマンド | 内容 |
|---|---|
| `help` | コマンド一覧を表示 |
| `status` | 設定の読み込み元、未保存の変更の有無、タイムスタンプを表示 |
| `show` / `show <sw>` | マクロの内容を読みやすく表示(全スイッチ / 指定スイッチ) |
| `dump` | 設定全体を 728 文字の 16 進数で表示(`load` でそのまま戻せる) |
| `set <sw> <step> down <hex>` | キーを押す |
| `set <sw> <step> up <hex>` | キーを離す |
| `set <sw> <step> tap <hex>` | 押して離す(メディアキーは `80xx`) |
| `set <sw> <step> rel` | 全キーを一括解除 |
| `set <sw> <step> wait <ms>` | 待つ。**ミリ秒は 10 進数**(1〜65535) |
| `set <sw> <step> clear` | そのステップを空にする |
| `load <728桁の16進数>` | 設定全体を置き換える(index.html の `.bin` と同じ中身) |
| `time <UNIX秒>` | 設定のタイムスタンプを変更する |
| `save` | 現在の設定を EEPROM に書き込む |
| `reload` | 未保存の変更を捨てて EEPROM から読み直す |
| `erase yes` | EEPROM を消去し、内蔵の既定値に戻す |
| `echo on` / `echo off` | 入力のエコーバックを切り替える |

**重要**: `set` / `load` / `time` は RAM 上の設定を即座に書き換えます(次にボタンを押したときから反映)。
EEPROM に反映されるのは `save` を実行したときだけです。保存せずに電源を切ると元に戻ります。
未保存の変更があるかは `status` で確認できます。

## 4. スイッチ番号

| sw | 割り当て | 既定マクロ |
|---|---|---|
| 0 | 右上ボタン | Ctrl+V |
| 1 | 右下ボタン | Ctrl+S |
| 2 | 左上ボタン | Ctrl+C |
| 3 | 左下ボタン | F4 |
| 4 | 上ダイヤル押し込み | F11 |
| 5 | 下ダイヤル押し込み | Ctrl+Shift+M |
| 6 | 上ダイヤル 時計回り | 画面の明るさアップ |
| 7 | 上ダイヤル 反時計回り | 画面の明るさダウン |
| 8 | 下ダイヤル 時計回り | 音量アップ |
| 9 | 下ダイヤル 反時計回り | 音量ダウン |

## 5. ステップの種類

| コマンド | 内部の type | code |
|---|---|---|
| `down` | 0 (押す) | HID キーコード(1 バイト) |
| `up` | 1 (離す) | HID キーコード(1 バイト) |
| `tap` | 2 (打鍵) | HID キーコード(1 バイト) |
| `rel` | 3 (制御) | 0(全キー、一括解除) |
| `wait` | 3 (制御) | 待ち時間 ms(1〜65535) |
| `clear` | 0 | 0(未設定) |

- code の最上位ビット(`0x8000`)が立っているものはメディアキー(Consumer Control)です。下位 15 bit が Usage ID で、種類に関わらず常に「押して離す」動作になります。
- 通常キーのコードは 1 バイト(`00`〜`FF`)です。それ以外は `ERR` になります。
- 1 スイッチあたり最大 16 ステップ、順番に実行されます。

### よく使う HID コード

| キー | code | キー | code |
|---|---|---|---|
| A〜Z | `04`〜`1D` | F1〜F12 | `3A`〜`45` |
| 1〜9, 0 | `1E`〜`27` | F13〜F24 | `68`〜`73` |
| Enter | `28` | 左 Ctrl | `E0` |
| Esc | `29` | 左 Shift | `E1` |
| Backspace | `2A` | 左 Alt | `E2` |
| Tab | `2B` | 左 Win | `E3` |
| Space | `2C` | 右 Ctrl / Shift / Alt / Win | `E4` / `E5` / `E6` / `E7` |
| ← → ↑ ↓ | `50` `4F` `52` `51` | Delete | `4C` |

| メディアキー | code | メディアキー | code |
|---|---|---|---|
| 音量アップ | `80E9` | 次の曲 | `80B5` |
| 音量ダウン | `80EA` | 前の曲 | `80B6` |
| ミュート | `80E2` | 再生 / 一時停止 | `80CD` |
| 画面明るさアップ | `806F` | 画面明るさダウン | `8070` |

その他のコードは index.html のメニューで選ぶと、`0x....` 形式で確認できます。

## 6. 変更の手順

### A. 1 ステップだけ直す

```
show 0
set 0 3 tap 29
show 0
save
```

### B. ショートカットを新しく作る(例: 右上ボタンを Ctrl+Shift+Esc にする)

```
set 0 1 down E0
set 0 2 down E1
set 0 3 tap 29
set 0 4 rel
save
```

- 元のマクロのステップが後ろに残る場合は、`set 0 5 clear` のように不要なステップを空にします。
- `down` で押したキーは、`rel`(または `up`)で離してください。ただしマクロの終了時に押したままのキーは自動で解除されます。

### C. index.html で作った設定を丸ごと書き込む

1. index.html を開いてマクロを設定します。
2. 「**Serial用 load コマンドをコピー**」ボタンを押します。
3. Serial ターミナルに貼り付けて Enter を押します(`OK (not saved yet...)` と返ります)。
4. `show` で内容を確認し、問題なければ `save` を送ります。

`.bin` から作る場合は、16 進数に直した 728 文字を `load ` の後ろに付けても同じです。
タイムスタンプは `.bin` / コピーしたコマンドに含まれる、保存時の時刻が使われます。

### D. 設定のバックアップと復元

```
dump
```

表示された 728 文字を保存しておき、戻すときは `load <その文字列>` と `save` を送ります。

### E. 既定値に戻す

```
erase yes
```

EEPROM を消去し、その場で内蔵の既定値(`macro_config.h`)に切り替わります。

### F. タイムスタンプを更新する(任意)

設定の更新日時を記録しておきたい場合に使います。動作には影響しません。UNIX 秒を 10 進数で渡します。

- Windows(PowerShell): `[DateTimeOffset]::UtcNow.ToUnixTimeSeconds()`
- macOS / Linux: `date +%s`

```
time 1800000000
save
```

2026-01-01 00:00:00 UTC(`1767225600`)より前の値は受け付けません。

## 7. 注意事項

- `save` はフラッシュの消去・書き込みを行うため、数十 ms の間キー入力や LED が止まります。通常の使用には支障ありません。
- フラッシュの書き換え回数には限りがあります(目安 約 10 万回)。内容が同じなら書き込みはスキップされますが、`save` の連打は避けてください。
- いずれかのマクロが実行中の `save` / `erase` は `ERR: a macro is running` で拒否されます。少し待ってから再実行してください。
- 1 行は最大 1024 文字です(`load` は約 735 文字なので収まります)。
- `load` はタイムスタンプが `FFFFFFFF` の設定を受け付けません(「未書き込み」と区別できなくなるため)。
- 通常のファーム更新(UF2 / PlatformIO の Upload)では EEPROM 領域は消えず、保存した設定は残ります。フラッシュ全体を消す `flash_nuke.uf2`(https://datasheets.raspberrypi.com/soft/flash_nuke.uf2) を使った場合は消えます。

## 8. トラブルシューティング

| 症状 | 原因と確認事項 | 対処法 |
|---|---|---|
| **コマンドの反応がない** | ・ボーレートの不一致<br>・改行コード（CR/LF）の未送信<br>・シリアル接続の切断 | 1. ターミナルの通信速度を `115200 bps` に設定する<br>2. 送信時に改行を含める設定にする<br>3. 再接続し、`Serial connected` と表示されるか確認する |
| **入力文字が二重に表示される** | ターミナルの「ローカルエコー」が有効になっている | コマンド `echo off` を送信するか、ターミナルのローカルエコー設定をオフにする |
| **`ERR: unknown command`** | コマンドのスペルミス | `help` を実行し、使用可能なコマンド一覧と表記を確認する |
| **`ERR: need exactly 728 hex chars`** | 送信データの不足または不要な文字の混入 | 貼り付け時にデータが途中で切れていないか、前後に不要なスペースや改行が入っていないか確認する |
| **再起動すると設定が元に戻る** | 変更が EEPROM に保存されていない | コマンド `save` を実行する<br>※ `status` を実行し、`Unsaved changes: no` になっていることを確認 |
| **起動時に `built-in default` と出る** | EEPROM の未初期化、またはデータ破損 | コマンド `save` を実行して現在の設定を書き直す |
